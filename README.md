# Werkstück – Testumgebung

Dieses Repository veröffentlicht ausschließlich die Testversion des öffentlichen Quellcodes aus [BTH840/werkstueck](https://github.com/BTH840/werkstueck).

Testadresse: https://bth840.github.io/werkstueck-test/

Unter Actions den Workflow „Test oder Live veröffentlichen“ starten. source_ref ist `main` oder eine vollständige Commit-SHA aus dem Hauptrepository. Die Website ist öffentlich; keine vertraulichen Entwürfe veröffentlichen.

Live wird separat im Hauptrepository freigegeben, mit derselben vollständigen getesteten Commit-SHA.
